#Hoax News Prediction - Indonesia
https://hoax-id.netlify.app/


Client-side machine learning hoax detection for Indonesian news, verified in real time with dual-source web checking, running entirely in the browser as an installable PWA.

AntiHoaxID classifies Indonesian-language text as Hoax or Fact using a Logistic Regression model that runs 100% in the browser (no backend server), then cross-checks the result against live web evidence from Google Search and TurnbackHoax.id in parallel. The final verdict blends the ML score and the web verification score, and every prediction comes with a human-readable explanation of which words drove the decision.
